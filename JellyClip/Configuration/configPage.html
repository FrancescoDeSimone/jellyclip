JellyClip

Creates clips from a video that is currently playing in the web client.

  1. Play a video, then use the Set start / Set end / Download clip buttons in the top-right corner of the player.
  2. The clip is cut server-side with ffmpeg and downloaded to your browser.

The clip UI is injected into the web client automatically when the server starts. If the web client was upgraded or the tags were removed, re-inject them below.

ffmpeg settings

Custom encoder arguments for clips. Leave empty for the built-in defaults (-c:v libx264 -preset veryfast -crf 23 -pix_fmt yuv420p -c:a aac -b:a 128k -ac 2 -movflags +faststart). Use {START} and {DURATION} placeholders if you need the clip times. The input file, audio stream mapping and output file are always appended automatically.
